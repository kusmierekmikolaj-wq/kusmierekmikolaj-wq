# Profile project marks

Original SVG identity assets for Mikołaj Kuśmierek's projects. AMSA uses a feedback ring and a focus point; Iskra uses a lightning bolt. The icons share a 128×128 grid, a rounded-square tile and a 22px profile-heading size. The existing reel-intel artwork remains in its own repository.
